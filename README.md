My work focuses on turning practical needs into useful products: from a provisional driving-exam preparation platform, to mobile portfolio experiences, academic decision-support prototypes, and business software in progress. ## Featured work

### [ikizame.rw](https://ikizame.rw/) · Provisional driving-exam platform

An online platform for practicing and preparing for Rwanda’s provisional driving examinations on phones and computers. The project is publicly accessible and maintained in the [`ikizame-app`](https://github.com/nzerneste250/ikizame-app) repository.

**Verified stack and capabilities:**

- Node.js, Express.js, MySQL, and JavaScript
- Responsive exam-practice experience for mobile and desktop users
- MTN MoMo and Airtel Money payment support with PayPack integration
- Nginx, PM2, Ubuntu VPS, and production deployment configuration

### [SMARTSTOCK](https://github.com/nzerneste250/SMARTSTOCK) · Under development

SMARTSTOCK is an **under-development** inventory and point-of-sale platform aimed at small and medium-sized businesses in Rwanda. Its repository describes workflows for products, stock, sales, receipts, and business monitoring; the project is not presented here as a launched commercial product.

**Current technical foundation:**

- PHP 8.3 and Laravel 13
- Laravel Sanctum and Laravel Tinker
- Vite, Tailwind CSS, Axios, and Laravel’s Vite integration
- Backend routes, application code, database migrations, tests, and frontend assets in the repository

The broader product direction includes offline-first workflows, quantity-based products, synchronization, dashboards, and mobile business operations as the project develops.

### [NEPortfolio](https://github.com/nzerneste250/MOB_A2_2527341) · Android portfolio application

An academic React Native portfolio application built with **Expo and TypeScript**. It presents profile information, education, skills, projects, and experience through a mobile interface, with editable profile data stored locally for offline use.

**Stack:** React Native · Expo · TypeScript · React Navigation · AsyncStorage · Expo Camera/Image Picker

### [Musanze Harvest Intelligence Service](https://github.com/nzerneste250/AI_A2_2527341) · Academic prototype

A reproducible **SWE 3513** machine-learning decision-support prototype using synthetic agricultural data. It predicts potato harvest quantity, classifies production risk, and groups farms with similar conditions through a Python/FastAPI service.

This is classroom decision support, not field-validated agronomy. The repository explicitly identifies its data as synthetic and its predictions as requiring human review.

**Stack:** Python · NumPy · pandas · scikit-learn · FastAPI · Uvicorn · pytest
